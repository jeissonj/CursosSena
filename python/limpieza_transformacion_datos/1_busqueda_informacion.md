1.Metodologías de análisis de datos
Existen diferentes metodologías utilizadas para el análisis de los datos, tales como ASUM-DM. (“Analytics Solutions Unified Method”), KDD. (“Knowledge Discovery in Databases”), SEMMA. (“Sample, Explore, Modify, Model, Assess”) y CRISP-DM. (“Cross-Industry Standard Process for Data Mining”).

Teniendo en cuenta que la metodología que se debe trabajar en este curso es CRISP-DM 

CRISP-DM. (“Cross-Industry Standard Process for Data Mining”): la cual permite llevar de manera organizada cada una de las etapas por la cuales debe pasar un proyecto de análisis de datos, incluyendo la limpieza y la trasformación de datos. Esta metodología facilita la creación de estrategias y el establecimiento de acciones necesarias para el cumplimiento de los objetivos propuestos en el negocio.
